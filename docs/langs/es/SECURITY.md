Esta política cubre la versión estable actual y master actual; las versiones anteriores no se mantienen por separado. La utilidad se ejecuta localmente con los permisos del usuario y modifica nombres en la carpeta elegida. Utilice árboles de directorios de confianza, copias de seguridad y los privilegios mínimos. No trabaje con datos que otros procesos estén modificando. No se promete reversión transaccional ni protección frente a cambios concurrentes arbitrarios.

## Informar de una vulnerabilidad

No publique detalles de vulnerabilidades en Issues o Discussions. Utilice GitHub Security → Report a vulnerability cuando esté disponible. Si no existe un canal privado, no revele detalles públicamente; solicite al responsable un medio de contacto seguro sin detalles técnicos. Incluya la versión, el sistema operativo y la consola, un ejemplo sintético mínimo, comportamiento esperado y real, impacto y registros depurados. Coordine la publicación tras la corrección.
