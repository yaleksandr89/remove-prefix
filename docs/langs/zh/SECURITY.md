本政策适用于当前稳定版本 和当前 master；更早版本不单独维护。工具以调用用户的权限在本地运行，并修改所选文件夹中的名称。请使用可信目录树、备份和最少所需权限。不要处理其他进程正在修改的数据。不承诺事务回滚或防止任意并发修改。

## 报告安全漏洞

请勿在 Issues 或 Discussions 中公开漏洞详情。可用时，通过 GitHub Security → Report a vulnerability 私下报告。如私密渠道不可用，请勿公开详情；向维护者请求安全联系方式，不提供技术细节。附上版本、操作系统和 shell、最小合成示例、预期与实际行为、影响及脱敏日志。修复后协调披露。
