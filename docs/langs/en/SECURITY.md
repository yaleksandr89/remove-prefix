# Security

[Русский](../../../.github/SECURITY.md) | **English** | [Español](../es/SECURITY.md) | [中文](../zh/SECURITY.md) | [Français](../fr/SECURITY.md) | [Deutsch](../de/SECURITY.md)

This policy covers the current stable release and current master; earlier releases are not maintained separately. The utility runs locally with the invoking user’s permissions and changes names in the selected folder. Use trusted directory trees, backups and the minimum necessary privileges. Do not run against data that other processes are modifying. Transactional rollback and protection against arbitrary concurrent changes are not promised.

## Report a vulnerability

Do not post vulnerability details in Issues or Discussions. Use GitHub Security → Report a vulnerability when available. If private reporting is unavailable, do not disclose details publicly; ask the maintainer for a secure contact channel without technical details. Include the version, OS and shell, a minimal synthetic example, expected and actual behavior, impact and sanitized logs. Coordinate disclosure after a fix.
