# Использование и примеры

[Скрипты для удаления префиксов из названий файлов и папок](../../../../README.md)

Требования: Git для клонирования; Windows 10/11 с PowerShell 5.1 или выше либо Linux/macOS с Bash 4.0+ и утилитами `find`, `mv`, `ps`, `awk`, `date`, `bc`. На macOS используйте Bash 4.0+ из `PATH`, а не штатный `/bin/bash` 3.2.

**Скрипты изменяют имена на диске. Сначала сделайте резервную копию и проверьте работу на отдельной копии данных. Не запускайте их от администратора или root без необходимости.**

## Windows (PowerShell)

```powershell
git clone https://github.com/yaleksandr89/remove-prefix.git
cd remove-prefix
.\scripts\remove_prefix.ps1
```

Если политика выполнения блокирует проверенный локальный скрипт, для текущего сеанса можно использовать `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned`, если это разрешено политикой организации. Не требуется запускать терминал от администратора или менять политику пользователя на Unrestricted.

Введите префиксы через запятую, затем путь к папке. Например, `ad_,pre_` и путь к тестовой директории. Корневая папка не переименовывается.

## Linux/macOS (Bash)

```bash
git clone https://github.com/yaleksandr89/remove-prefix.git
cd remove-prefix
bash scripts/remove_prefix.sh
```

Введите префиксы через запятую, затем путь к папке. Например, `ad_,pre_` и путь к тестовой директории. Корневая папка не переименовывается.

![Пример запуска Bash](../../../assets/how-use-linux.gif)

## Порядок обработки

Префиксы применяются в порядке ввода, с учётом регистра, только к началу имени. Каждый префикс удаляется повторно, пока совпадает. Например, при `ad_,pre_` имя `ad_ad_pre_photo.jpg` становится `photo.jpg`, а `my_ad_photo.jpg` остаётся прежним. Обход идёт от вложенных элементов к родительским папкам. Не используйте активные, общие или системные каталоги; работу выполняйте на стабильном дереве без параллельного изменения имён. Не рассчитывайте на автоматический откат или обработку скрытых элементов Windows (по умолчанию PowerShell их не перечисляет).
